# In This Town — procedural blocky shorts in JavaScript

This folder turns an episode script into a finished 9:16 short, with no Roblox assets and no
hand-made models. Characters, houses, trees, the sky ocean, whales, fish, jellyfish, the giant hands
and the eye are all generated by code with three.js. The music and sound effects are synthesized in
Python, so there is nothing to license.

Episode 6 output: `output/InThisTown_Episode06_OceanSky.mp4` (1080×1920, 30 fps, H.264 + AAC, about 61 s)
and `output/InThisTown_Episode06_OceanSky_thumbnail.jpg`.

## Pipeline

```
episodes/ep06_ocean_sky.json   script: voiceover lines, scene numbers, caption chunks and highlights
        │
tools/tts.py                   narration per line (Kokoro offline TTS, or ElevenLabs if a key is set)
        │                      → build/ep06/voice/*.wav + timeline.json (line, caption and scene timings)
render.js + web/               headless Chromium renders each frame as a pure function of time t
        │                      (deterministic, so frame ranges render in parallel workers)
tools/audio.py                 procedural score + SFX, timed from the same events, then mixed and ducked under the voice
        │
ffmpeg                         H.264/AAC MP4, loudness-normalised to −14 LUFS
```

Run everything:

```bash
npm install
KOKORO_MODEL=/path/kokoro-v1.0.onnx KOKORO_VOICES=/path/voices-v1.0.bin PYTHON=/path/venv/bin/python \
  ./make_episode.sh episodes/ep06_ocean_sky.json 3
```

The Kokoro model files come from the `model-files-v1.0` release of `thewh1teagle/kokoro-onnx` on GitHub.
Python packages: `kokoro-onnx soundfile scipy numpy`.

For ElevenLabs voices, set `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_NARRATOR` and `ELEVENLABS_VOICE_MOTHER`
(voice ids), then rerun. `tools/tts.py` switches to ElevenLabs automatically and the caption timings follow
the new audio. OpenRouter doesn't proxy ElevenLabs text-to-speech, so you need an ElevenLabs key.

To preview while editing, render a few stills at quarter resolution and put them on a contact sheet:

```bash
node render.js stills ep06 0.25 1 5 10 20 30 40 50 60
python3 tools/sheet.py build/ep06 build/ep06/sheet.jpg 1 5 10 20 30 40 50 60
```

## Engine (`web/engine/`)

| file | what it makes |
|---|---|
| `character.js` | R6-style blocky avatars (rounded boxes): clothing, hoodie, hair styles, canvas-drawn faces (wonder, curious, worried, scared, shock, calm, creepy…), poses (idle, look up, point, wave, run, scared, lean). |
| `town.js` | Pastel suburb (houses, roofs, windows, hedges, trees, streetlights, roads, town square, fountain, the warning sign). Static geometry is merged per material. Emma's house has a real two-storey interior with a staircase, window openings and lights. |
| `ocean.js` | The suspended ocean: a dense membrane shader with ripples, caustic light, colour grading, giant-hand indentation (a hand SDF shared with the hand meshes), glowing cracks (Voronoi), the hole and the eye, plus the sky dome. |
| `creatures.js` | Whales (lathe body, flapping flukes), instanced fish schools that can freeze in place, glowing jellyfish with light pools on the ground. |
| `core.js` | Shared uniforms and the world-space caustic patch applied to every outdoor material. |

`web/episodes/ep06.js` is the director: lighting palettes over time (day → night → evening → purple → red →
dread → crack), the shot list (camera paths keyed to narration lines), character blocking, captions and the
camera-shake and flash overlays.

## Making the next episode

Copy the episode JSON (lines + captions), then copy `web/episodes/ep06.js` and change its palettes, shots and
props. The engine modules are meant to be reused across episodes so the look stays consistent: same Emma,
same town, same caption style.
